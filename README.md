# Computer Networking Projects

My solutions to the programming assignments in *Computer Networking: A Top-Down Approach* (Kurose & Ross, 8th ed.). All code written from scratch in Python 3, standard library only.

| # | Project | Chapter | Run |
|---|---------|---------|-----|
| 1 | Web Server | 2 | `python 01_web_server/server.py` |
| 2 | UDP Pinger | 2 | `python 02_udp_pinger/server.py` then `client.py` |
| 3 | Mail Client (raw SMTP) | 2 | see docstring in `mail_client.py` |
| 4 | Caching Web Proxy | 2 | `python 04_web_proxy/proxy.py` |
| 5 | Reliable Transport (GBN / stop-and-wait) | 3 | `python 05_reliable_transport/rdt.py --protocol gbn` |
| 6 | ICMP Ping | 5 | `sudo python 06_icmp_ping/ping.py google.com` |
| 7 | Distance-Vector Routing | 5 | `python 07_distance_vector/dv.py` |
